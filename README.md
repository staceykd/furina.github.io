## Getting started (local preview)

1. Clone the repository:

```bash
git clone https://github.com/staceykd/furina.github.io.git
cd furina.github.io
```

2. Open `index.html` directly in your browser (double-click), or run a simple local server to avoid CORS and file-loading issues:

```bash
# Python 3
python3 -m http.server 8000
# Then open http://localhost:8000 in your browser
```

or using Node.js http-server:

```bash
npm install -g http-server
http-server -p 8000
```

## Deploying (GitHub Pages)

This repository is suitable for GitHub Pages. To publish:

- Enable GitHub Pages in the repository settings (Pages) and select the default branch (usually `main` or `master`) and the `/ (root)` folder.
- GitHub will publish the site at `https://staceykd.github.io/` (or the custom domain if configured).

No special build step is required unless your site uses a static site generator or build tooling.
